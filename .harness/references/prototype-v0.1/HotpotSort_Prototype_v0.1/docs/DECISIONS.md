# 决策记录

| ID | 采用的决定 | 分类 | 替换位置 |
|---|---|---|---|
| D01 | 5 格暂存、2 开放/4 总订单、每单 3 件 | 用户确认 | 公共规则与 HUD；不要只改数据而不改固定布局 |
| D02 | 单件食材点击，不搬整盘 | 用户方向 + 静态依据 | `GameSession.Tap` / `Game.tap` |
| D03 | 初始前 10 盘最多种类优先 | 静态依据 | `PickOpening` / `pickOpening` |
| D04 | 并列用 kind 升序 | 本版确定性替代 | 开局排序；非原生 Dictionary 复现 |
| D05 | 顺序供给 + 高度暂停 | 静态依据 | `PlateWorld` / `World` |
| D06 | 圆形堆积、具体尺寸和坐标、生成点防重叠 | 本版替代 | `PlateWorld.cs` / `physics.js` 与规则 JSON |
| D07 | 保留 60 行类别权重，成本使用近似 | 部分依据 + 本版替代 | `CandidateCosts` / `candidateCosts` |
| D08 | 类别缺候选则选最小成本集合 | 本版替代 | `PickRefill` / `pickRefill` |
| D09 | 新单库存必须扣除其他单预留 | 本版库存安全约束，有相关原分析依据 | `RemainingAvailable` / `remainingAvailable` |
| D10 | 默认第五格占满后自动结算，再失败 | 待用户确认的默认实现 | `failOnFull`；菜单提供两种模式 |
| D11 | 输入事务期间短暂锁定；动画不拥有 Token | 本版工程约定 | 应用层 `busyUntil`；纯逻辑 `Settle` |
| D12 | 尾局无可用三件组时目标槽留空 | 本版确定的边界 | 新单选择返回 `kind=-1` |
| D13 | 没有目标固定序列、没有求解器和隐藏救场 | 范围限制 | 源代码没有后台内容重写入口 |
| D14 | Unity 2022.3 主工程 + 独立 HTML 试玩 | 本次交付默认选择 | 引擎尚非用户先前明确指定 |
| D15 | 不复用原包美术，不分发字体 | 交付素材约束 | `art.js`、导出工具、系统字体回退 |

任何改变 D01、D02 或新增机制，都应改 SPEC 版本，而不是混在“修 bug”中。
