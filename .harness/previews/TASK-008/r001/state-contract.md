# TASK-008 v1 · HC-02 好友榜表现合同候选

Status: Preview Candidate Ready。Mode: implementation_preview。Input: HC-01-v1 Accepted。
Target: HC-02-v1；Rollback: HC-01-v1、既有v7/v8好友榜视觉家族。

## 布局与数据诚实性

420×900逻辑框架，建议卡x30/y150/w360/h616；标题“好友榜”，副标题“累计每日首通次数”。卡内列表视口x50/y240/w320/h350；底部主刷新操作与低权重返回首页。实际 safe-area映射沿用LogicalFrame。360px预览正文14–17px、昵称13px以上、辅助至少12px；行高66px、头像38px，真实昵称单行省略，触控不依赖头像。

预览正常/本人页面仅绘制“真实头像 / 微信昵称 / 名次 / 首通次数”的字段标签。没有真实微信数据可供展示，因此没有编造任何名字、头像、分数、排名；这些标签不是生产文案。真实数据到达后由开放数据域绘制。未知字段使用“—”或中性空位，零分只在来源明确为0时展示；图片失败保持空位，不合成人物。

| 状态 | 内容 | 操作 |
|---|---|---|
| 初次加载 | 图标＋正在获取好友成绩…；不画假记录 | 加载禁用；返回首页可用 |
| 正常 | 真实头像昵称、累计首通、名次、本人标识 | 刷新、返回首页；视口内滚动 |
| 只有本人 | 真实本人记录＋还没有其他好友成绩＋通过微信右上角邀请好友 | 刷新、返回首页 |
| 无成绩 | 还没有好友成绩；完成一次每日挑战后即可积累首通次数 | 刷新、返回首页 |
| 加载失败 | 好友榜暂时没加载出来；请检查网络后重试 | 重试、返回首页 |
| 明确权限/关系链不可用 | 暂时无法获取好友数据；当前微信状态无法读取好友榜 | 重新尝试、返回首页；无新增授权入口 |
| 静默登录失败 | 暂时无法连接微信；你仍然可以继续游戏 | 重试连接、返回首页 |
| 有真实旧列表且刷新中 | 保留已返回记录＋正在更新… | 更新禁用；返回首页可用 |

同次数同名次，使用真实累计每日首通分值，排序由开放数据域负责。没有群榜/全服榜页签、头像饰品、奖杯奖励和页面分享按钮。主域不接收或保存昵称、头像、排行逐行数据。列表/本人信息只在开放域纹理中出现；主域负责卡壳、非敏感状态、刷新/关闭和安全区矩形。

## 跨域界面合同需求

主域提供show/hide/refresh及列表视口尺寸与像素比例；子域返回不含好友资料的loading/ready/selfOnly/empty/permissionUnavailable/error状态和当前请求代次。好友数据始终留在子域。真实列表滚动由子域或现有明确输入桥接负责，不能用整屏点击透传；关闭后销毁/隐藏纹理并清理输入。协议确切字段由Designer冻结。

昵称使用微信开放数据域系统字体；标题与主域按钮使用TASK-002精简字体。名次/首通数字等宽对齐；长昵称省略不得挤压右列。缓存存在时刷新失败保留原真实列表并标注“更新失败，请重试”；不把缓存误称最新。
