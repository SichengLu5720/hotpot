## 可编辑与复现

`compose.py` 是完整复现配方。需要 Pillow、Windows 微软雅黑本地字体；字体仅用于本地预览，不复制/授权游戏字体。正式字体由项目依赖确认，不能从 Windows 拷贝随包分发。

在工作区执行 `python .harness/previews/TASK-002/v001/compose.py`。脚本以原图为底层，按函数顺序绘制原生 UI 几何层、独立 PNG 层、独立文字层，2 倍抗锯齿后回到原始像素。所有文字、坐标、颜色、食材 ID 和盘位可直接编辑。生成 content-manifest.json 自动记录源图/素材/输出摘要与尺寸；摘要不是视觉合格证明。已接收/批准后禁止原路径覆盖，后续修改需新版本目录。

## 给 Builder 的视觉映射

| 元素 | 分类 | 绑定/表现意图 |
|---|---|---|
| 食材、盘子 | reuse | 复用独立 PNG，保持透明度、形状和 ID，不从预览裁图。中心 pivot；盘子阴影不作为可点击食材。食材坐标仅构图参考，实际物理由场景负责。 |
| 订单卡、暂存、按钮、底色 | native UI | 奶油底、墨绿字、珊瑚主按钮、浅绿次按钮；圆角与描边由控件生成。两启用卡计数与进度独立，另两卡保留禁用态。 |
| 标题、说明、计数、日期、结果 | native UI | 全部独立 Text 控件，动态值来自会话/核心。预览 PNG 不可作为运行时整屏 UI。 |
| 暂停 | native UI | 顶部右侧暂停按钮；模态层下仍显示当前盘区，遮罩拦截盘区点击。继续/退出只提交语义意图。 |
| 今日入口 | native UI + reuse | 日期来源于会话；开始今日挑战。入口装饰复用食材 PNG。 |
| 结果 | native UI | 完成/未完成标题、时长、玩家点击、拒绝点击、暂存峰值、自动吸收、完成订单、重试；示例数值不是测试事实。未完成显示实际失败原因。无星级、段位。 |
| 异常 | native UI | Aborted 显示“本局已中止”及提供方原因，和溢出失败区分。不得把暂存 5/5 当失败。 |
| 新资产 | none | asset_contract 为空，本轮无概念生产或正式美术生产。 |
