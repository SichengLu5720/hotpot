# 新 Harness 工作流草案

本文保存新 Harness 已确认的工作流条款，供后续统一打包；当前仅落盘项目导航部分，不表示整套新 Harness 已安装或替换仓库根 AGENTS.md。

## 项目导航与 AI 自动维护

- 项目采用一份轻量项目导航，建议路径为 `docs/PROJECT_NAV.md`；已有同等入口时复用，不重复创建。
- 模块收录标准：**Agent 修改该模块时，是否需要一个独立入口才能快速找到相关代码、配置、资源和检查。** 需要则收录，不按功能大小机械划分，不维护全文件清单。
- 开工时按导航定位当前模块，并核对实际实现；导航是查找入口，不覆盖 SPEC 或代码事实。
- 工作包完成时，负责 Agent 根据本次改动判断是否触发导航更新。只有模块增删、关键入口变化或反复定位困难时更新；无变化不改文档、不增加维护记录。
- 触发后的事实性导航修订由 AI 在已分配的写入范围内自动完成，无需逐次请用户批准。并行工作包只回传更新建议，由指定 Integrator 串行写入共享导航。
- 验收仅检查受影响导航项的准确性和可定位性，不为维护导航启动全项目扫描、构建或全量 QA。
- 具体收录粒度、活动模块示例、更新步骤与完成条件见 [项目导航工作手册](handbooks/project-navigation.md)。

后续安装新 Harness 时，将本节的维护要求接入 AGENTS.md 的开工与完成流程；在此之前，本草案不会自动使其他任务加载或执行这些规则。
