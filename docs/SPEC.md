## Product Goal

- 制作可在微信小游戏中稳定运行的《火锅消消》每日挑战。
- 当前交付目标：并行完成玩法、平台与美术整合，使正式微信包在微信开发者工具中完整走通冷启动、远程资源、静默登录与云档案、完整一局、奖励、好友榜、失败复活和重试；修复明显运行错误后上传微信后台，由用户设置体验版并做最终风格判断。
- 未经新的明确授权，不提审、不正式发布。

## Core User Flow

- Entry：本地入口页立即可用；远程正式资源在点击开始后准备。
- Trigger：用户点击开始，资源完整校验并激活后才创建当日挑战会话。
- State Changes：登录和档案同步不阻塞入口；若登录在一局开始后完成，当前局保持原本地档案，回到入口再合并并切换微信档案。
- Success：完成当日挑战，写入首通并排队同步；好友榜刷新真实累计首通次数。
- Failure / Cancel：资源、分享、广告、网络或云同步失败不得伪造成功；允许按现有入口重试。终局、退出、重试和旧会话回调必须取消或去重。

## Rules and Data

- 当前玩法、订单、库存、供给、遮挡、点击、失败复活、奖励额度和每日挑战规则以本文件下方合并的既有规则为准。
- 分享奖励每日三次：首次立即、第一次生效后等待 5 分钟、第二次生效后等待 15 分钟，北京时间 06:00 重置。
- 失败复活将所有暂存食材移入一只大盘，时间到不弹暂存满复活。

# Game Spec

## Product

- Working title: 火锅消消
- Genre: 参考 Fish Sort Puzzle 的点击式休闲整理解谜游戏。
- Target platform: 微信小游戏，竖屏、微信内独立运行。
- Engine and version: Unity 6000.0.26f1。
- Target session length: 5–7 分钟；单局倒计时为 10 分钟。进入主玩法后倒计时先保持 `10:00`，盘子仍按既有节拍持续生成、下落和碰撞；只有玩家第一次成功点击可操作食材，且核心确认该食材进入订单锅或暂存碟后，挑战倒计时才开始。空白、遮挡或不可操作食材、暂停、设置、道具与奖励入口均不启动倒计时。重试或新一局重新等待首次有效操作；后续引导关卡可使用此未计时阶段，但引导内容不属于当前实现。
- Input method: 点击。玩家不使用拖拽；支持暂停、同日重试、退出、道具和广告/分享入口。
- Monetization: 以激励视频为主；提示、清空暂存和刷新盘面也允许以分享替代。第四口锅提前解锁只通过激励视频获得。
- Target audience: 微信休闲用户，重点面向女性用户及《羊了个羊》《抓大鹅》同类玩家。

## Player Promise

玩家在热闹的火锅桌上，从同平面碰撞、互不重叠的食材盘中找出目标食材，让食材爽快地下入对应火锅。玩家通过观察、取舍和清理盘面，体验整理、配对与连续完成订单的爽感。

## Core Loop

1. 观察当前订单小锅、暂存区和下方食材盘，找出可用的目标食材。
2. 点按或按住后松开露出的食材：匹配订单的食材飞入对应小锅；暂时不匹配的食材进入五格暂存小碟。
3. 三个同类食材完成一口锅，整锅端走并补入新订单；持续清理全部订单以通关。

## Core Rules

### Player

- 玩家只能操作当前可见且位于有效操作区域的食材；快速点按或按住后松开均可收集。按下后锁定食材，轻微手指漂移不影响，明显超出点击容差则取消；该手势不形成拖拽操作。盘子之间不存在上下层遮挡。
- 匹配任一开启订单的食材自动选择可接收该食材的订单小锅并飞入锅中。
- 不匹配开启订单的食材进入暂存区。后续出现匹配订单时，暂存食材自动飞入对应小锅。
- 每口订单小锅需要 3 个同类食材；锅内食材沉入红汤，以订单牌中的 `1/3`、`2/3`、`3/3` 表示进度。
- 后续补单以 Difficulty 1 原始权重表为基础，保留现有暂存、进度、成本近似、预留及去重逻辑；新局不再使用后期80/20保护或保护池暂存分类加权。仅保留下文前15单等概率保护。此实现为现有基础选单的调整，不宣称完整原作复刻。
- 提示高亮一个当前可点击且匹配订单的食材，不自动代点；清空暂存将全部暂存食材组成一个混合盘追加到生成队列末尾；打乱仅重排当前剩余盘子位置，不改盘内内容或生成队列。每种道具均可通过激励视频或分享获得。
- 手动暂停、微信切到后台和观看激励视频期间，倒计时均停止。

### World / Board / Level

- 单局为正式的每日挑战玩法；每日内容和挑战状态必须可稳定复现。
